# OnlyStaff — деплой на Netlify

## Структура
```
index.html                     — лендинг, польская версия по умолчанию (root /)
pl/index.html                  — та же версия, статически отданная под /pl/ (title/meta уже на pl)
ru/index.html                  — русская версия, статически отданная под /ru/ (title/meta уже на ru,
                                  html lang="ru", canonical/og:url/og:locale переставлены на ru)
robots.txt, sitemap.xml        — добавлены, ссылаются на /pl/ и /ru/ с hreflang
google-apps-script/Code.gs     — приём заявок в Google Таблицу
assets/favicon.svg, apple-touch-icon.png, og-image.jpg — сделаны как рабочая
                                  заглушка в цветах сайта (тёмно-синий #0E151D + акцент #2445D6),
                                  замените на брендовые, когда будут
privacy.html, impressum.html   — готовы, на данных Only Staff sp. z o.o.
```

Важно: `index.html`, `pl/index.html` и `ru/index.html` — три отдельных файла.
Если правите текст/логику лендинга, правьте все три (или пересобирайте `pl/`
и `ru/` из корневого `index.html`, заменяя только блок `<head>` под язык —
см. комментарий в начале каждого файла).

## Осталось реально нужное от вас

1. **Google Apps Script** — убедитесь, что URL в `CONFIG.formEndpoint` (в `index.html`,
   `pl/index.html` и `ru/index.html`) — это ваш актуальный `/exec`-адрес развёрнутого
   `Code.gs`, и что заявка реально долетает до таблицы. Я не могу вызвать
   script.google.com из песочницы, чтобы проверить это за вас — протестируйте отправку
   формы вручную перед запуском.
2. **og-image, favicon, apple-touch-icon** — рабочие, но брендовые заглушки (просто текст
   на фирменных цветах). Не блокируют запуск, но стоит заменить на нормальную графику.
3. Медиа/фото объекта — в коде есть готовое место под фото (`.about-fig`, закомментировано
   в трёх файлах), не обязательно.
4. **Юридическая вычитка Impressum** — данные реальные, но перед публикацией стоит дать
   на разовую проверку юристу, знакомому с немецким правом (TMG/MStV), как и написано
   в заметке на самой странице.

## 1. Google Apps Script — 5 минут

1. Создайте новую Google Таблицу.
2. Расширения → Apps Script → вставьте `google-apps-script/Code.gs`.
3. (Опционально) впишите e-mail в `NOTIFY_EMAIL` в начале файла — будет письмо на каждую заявку.
4. Развернуть → Новое развёртывание → тип **Веб-приложение**, доступ **Все (Anyone)**.
5. Скопируйте URL (`/exec`) → вставьте в `index.html` → `CONFIG.formEndpoint`.
